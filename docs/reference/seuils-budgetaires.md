# Seuils budgétaires (à partir de V2)

| Seuil | Action |
|---|---|
| 50 % | Information dans le tableau de bord |
| 70 % | Notification FinOps |
| 80 % | Alerte au propriétaire du service |
| 90 % | Alerte critique et analyse obligatoire |
| 100 % | Blocage, limitation ou validation exceptionnelle, selon la politique de l'offre |
| Dépassement anormal | Incident FinOps |

Le choix entre blocage et alerte dépend de la criticité. Un agent métier critique n'est pas forcément interrompu à 100 % ; une nouvelle session Software Factory peut être refusée jusqu'à validation.
