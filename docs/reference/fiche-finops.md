# Fiche FinOps d'un composant (à partir de V2)

| Information | Description |
|---|---|
| Identifiant | Identifiant stable dans le catalogue |
| Type | Modèle, agent, API, stockage, runtime, connecteur, service partagé |
| Offre associée | Software Factory, Agent Platform, Model Gateway… |
| Propriétaire | Équipe responsable |
| Environnement | Développement, recette, production |
| Mode de facturation | À l'usage, provisionné, forfaitaire, partagé |
| Unité de consommation | Tokens, requêtes, minutes, capacité, stockage |
| Budget | Mensuel ou annuel |
| Seuils d'alerte | Pourcentages ou montants |
| Méthode d'attribution | Société, utilisateur, projet, agent, session, application |
| Règle de répartition | Pour les coûts partagés |
| Métriques d'usage | Indicateurs d'utilisation réelle |
| Métriques techniques | Disponibilité, erreurs, latence, saturation |
| Critère d'optimisation | Condition de redimensionnement |
| Critère de suppression | Condition identifiant une ressource inutilisée |
| Rétention | Durée de conservation des métriques et journaux |

Un composant dont la consommation ne peut être ni expliquée ni attribuée n'est pas terminé.
