# Tags obligatoires

| Tag | Exemple |
|---|---|
| environment | dev, test, prod |
| offer | software-factory |
| component | model-gateway |
| owner | ai-platform-team |
| cost-center | CC-1234 |
| managed-by | terraform |
| criticality | high |
| data-classification | internal |
| service-id | AI-SVC-001 |
| lifecycle | active |
| expiration-date | Date de fin prévue d'une ressource temporaire |

Les tags servent à analyser le coût des ressources. Ils ne remplacent pas le registre d'usage : un modèle partagé entre sociétés se répartit selon les consommations réelles, pas selon les tags.
